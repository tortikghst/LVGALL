# GhostEvent

Платформа для поиска и аренды оборудования для мероприятий.  
Репозиторий содержит две независимые части: **backend** (NestJS API) и **frontend** (React-приложение).

## 🚀 Быстрый старт (Docker Compose)

```bash
git clone https://github.com/tortikghst/GhostEvent.git
cd GhostEvent
docker-compose up -d --build
