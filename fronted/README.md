# GhostEvent Frontend

Клиентская часть платформы для аренды оборудования.  
Реализована на **React** с использованием **TypeScript**, **Vite**, **React Router**, **Axios**, **TailwindCSS**.

## 🛠️ Технологии

- React 18
- TypeScript
- Vite (сборщик)
- React Router DOM (маршрутизация)
- Axios (HTTP-клиент)
- TailwindCSS (стилизация)
- React Hook Form + Zod (валидация форм)

## 🚀 Запуск локально

```bash
# 1. Перейдите в папку frontend
cd GhostEvent/frontend

# 2. Установите зависимости
npm install

# 3. Настройте переменные окружения (опционально)
cp .env.example .env   # или создайте .env
